# Capturas de QA local — Galerias Digitais v1

Desktop: 1440 × 900. Celular: 390 × 900. PNGs de página completa, incluindo elementos fixos na posição do viewport inicial. Capturas produzidas por `e2e/portal/galerias-v1.spec.ts` e inspecionadas visualmente.

Identidades, clientes, e-mails e conteúdo exclusivamente sintéticos. Auth GoTrue, Next, Server Actions, PostgREST e SQL reais em ambiente Docker descartável sem rede externa. A mídia é SVG local substituído no navegador; URLs R2 assinadas com credenciais sintéticas. Estas imagens NÃO comprovam R2 nem produção. Link e código mascarados na tela de compartilhamento.

- `fotografo-lista-*`: lista e última seleção recebida.
- `fotografo-fotos-*`: grade e envio.
- `fotografo-compartilhar-*`: geração de link/código (mascarados).
- `fotografo-selecoes-*`: duas revisões e exportação CSV.
- `cliente-entrada-*`: código, sem conta.
- `cliente-galeria-*`: favoritas salvas e recuperadas após recarga.
- `cliente-entrega-*`: confirmação após segunda revisão.
- `cliente-revogado-*`: acesso negado após revogação.
